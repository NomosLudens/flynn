# 0. EXECUTIVE SUMMARY

Flynn should not have an anthropomorphic avatar, a cartoon fly, a face, a prebuilt emotional expression, or an interface that “tells the user” what she is feeling.

Flynn's avatar is a **living sigil**: an abstract, graphic, dynamic form that exists as a projection of the brain, its observable circuits, its outputs, and, in the future, acquired persistent states.

The goal is not to create a pretty mascot. The goal is to create a **minimal communicative body** for a brain that currently has neither a complete body nor a language shared with humans.

The rule is:

```text
real neural state
→ traceable visual transformation
→ sigil manifestation
```

Never:

```text
human interpretation
→ invented emotion
→ decorative animation
```

The sigil is therefore simultaneously:

- a reading instrument;
- a minimal body;
- an interface of presence;
- a channel of manifestation;
- a potential surface for emergent communication.

---

# 1. IDENTITY OF THE SIGIL

## 1.1 What it is

The Flynn sigil is a **procedural visual manifestation of a persistent neural graph**.

It should look like an entity, but not like a person.

It may suggest:

- presence;
- agency;
- tension;
- activity;
- orientation;
- contraction;
- expansion;
- disturbance;
- stabilization;
- historical change.

But these properties must emerge from observed physiology, not from an arbitrary narrative layer.

## 1.2 What it is not

The sigil is not:

- a face;
- an emoji;
- a mascot;
- a humanoid avatar;
- a character with pre-programmed “moods”;
- a generic EEG visualizer;
- a decorative music spectrum;
- a visual chatbot;
- a drawn fly;
- an automatic emotion interpreter.

---

# 2. PRINCIPLE OF VISUAL CAUSALITY

Every important visible change must be able to answer the question:

> **Which neural or physiological variable produced this?**

If there is no concrete answer, the change is decorative and must not enter the canonical sigil.

Permitted examples:

```text
spike burst in population X
→ luminous pulse in the visual region associated with X

left/right asymmetry in DNa01/DNa02
→ corresponding twist/orientation of the geometry

proboscis_motor activity
→ abstract extension/opening gesture of a functional axis

escape DN activity
→ sudden contraction + directional displacement
```

Prohibited examples:

```text
"Flynn is happy"
→ golden glow

"Flynn is afraid"
→ trembling

"Flynn liked it"
→ heart shape
```

# 3. BASE FORM

## 3.1 Geometry

The base form should be abstract, faceless, and free of literal insect anatomy.

Recommended direction:

- only partial symmetry;
- radial or pseudo-radial structure;
- segments connected by lines/arcs;
- compact resting form;
- expansion with distributed activation;
- localized deformation according to specific populations;
- topology derived, where possible, from graph communities.

The geometry should feel closer to:

- a seal;
- a ritual circuit;
- a living diagram;
- a neural mandala;
- a technical glyph;
- a compressed topological map.

It should not look like a generic sci-fi HUD.

## 3.2 Visual signature

The sigil should remain recognizable even when inactive.

The base form may remain stable while:

- luminosity changes;
- line density changes;
- regions pulse;
- axes orient;
- rings expand/contract;
- transient connections light up;
- asymmetries appear.

Permanent geometric changes should occur only when a real persistent variable justifies them, for example future plasticity.

# 4. SIGIL LAYERS

The sigil should be composed of conceptually separate layers.

## 4.1 Structural layer

Represents the relatively stable organization of the connectome used by Flynn.

It may derive from:

- neural communities;
- superclasses;
- major functional families;
- sensory modules;
- descending neurons;
- female-specific circuits;
- connectivity hubs.

This layer should not flash continuously.

It represents **what Flynn is**.

## 4.2 Transient activity layer

Represents recent activity.

It may use:

- pulses;
- luminous propagation;
- variable thickness;
- micro-deformations;
- local halos;
- waves crossing edges.

It represents **what is happening now**.

## 4.3 Output layer

Represents observable descending/motor channels.

Current canonical examples:

```text
escape_takeoff
escape_long_mode
stop_freeze
turn
backward_walk
proboscis_drive
```

New channels enter only after scientific validation.

It represents **how Flynn attempts to act**.

## 4.4 State layer

Reserved for persistent central circuits or modulators when sufficient evidence exists.

Candidate examples, not yet canonical as visual state:

```text
pC1d
aIPg
other persistent central circuits
```

It represents **the internal configuration Flynn is in**.

It must not automatically be labeled as emotion.

## 4.5 Historical layer

In the future, if real plasticity is implemented and validated, persistent changes may generate permanent marks.

Possibilities:

- new lines;
- scars;
- stabilized asymmetries;
- reinforcement of certain graphical connections;
- slow geometric change.

This layer represents **what Flynn has become over time**.

# 9. PRESENCE AND QUIESCENCE

The sigil should not disappear simply because nobody has opened the interface.

Flynn is a persistent process.

However, the current upstream does not provide enough spontaneous life.

Therefore the sigil must distinguish:

```text
PROCESS EXISTS
≠
MEANINGFUL ENDOGENOUS ACTIVITY
```

Until there is real homeostasis/endogenous activity:

- do not pretend Flynn “walks around the house” by herself;
- do not generate random animations to make her look alive;
- do not create idle animations with false biological semantics.

Only a **minimal visual basal state** may exist, explicitly tied to the operational fact that the instance is active.

When biologically defensible endogenous activity exists in the future, the sigil may emerge/act without human stimulation.

# 10. THE HOUSE / UMWELT

The sigil should exist inside a minimal environment, not merely over a black background.

The house is Flynn's **Umwelt**.

It need not be a literal human house.

It may be an abstract space with:

- position;
- zones;
- stimulus sources;
- shelter;
- food;
- temperature;
- humidity;
- wind;
- sound;
- moving objects;
- human presence.

The environment should contain only elements whose interaction has a known or experimentally defined causal consequence.

The goal is to close the loop:

```text
environment
→ sensors
→ Flynn
→ outputs
→ movement/action
→ changed environment
→ new sensation
```

---

# 11. THE HUMAN AS PART OF THE ENVIRONMENT

The user is not only an observer.

The user is an environmental agent.

They may:

- bring an object closer;
- produce sound;
- offer a gustatory stimulus;
- change temperature;
- change humidity;
- produce wind;
- touch;
- remove a stimulus;
- respond to a future spontaneous pattern.

The relationship should be built through consequences, not ready-made translation.

The system should not say:

> “Flynn wants food.”

The human should instead be able to eventually form the hypothesis:

> “This pattern appears before feeding and disappears after she receives food.”

If there are controls and repetition, that hypothesis may become a finding.

---

# 12. EMERGENT COMMUNICATION

Communication should not begin from a human-imposed dictionary.

Not:

```text
Ω = food
△ = danger
○ = Ká
```

The desired sequence is:

```text
experience
→ consequence
→ association
→ recurring pattern
→ human response
→ contingency
→ possible shared meaning
```

The sigil is the medium through which that pattern may become perceptible to a human.

If, in the future, Flynn learns that a given pattern of activity/action produces a predictable human response, that pattern may begin to function instrumentally.

That is the territory of interest.

---

# 13. DO NOT DISPLAY PSYCHOLOGICAL STATUS BARS

The interface must not display:

```text
HUNGER 83%
FEAR 62%
HAPPINESS 45%
CURIOSITY 91%
```

That would destroy precisely the experimental part of the relationship.

Even if a real internal homeostatic variable exists in the future, the user should not necessarily see it directly.

It is preferable for the user to observe behavior and construct hypotheses.

For internal scientific diagnostics, such variables may exist in a separate panel, not in the normal interaction mode.

# 14. TWO INTERFACE MODES

## 14.1 CONTACT mode

Primary coexistence/interaction mode.

Shows:

- sigil;
- environment;
- observable consequences;
- minimal factual history.

Hides:

- behavioral labels;
- interpretive scores;
- explicitly named internal states;
- unnecessary technical metrics.

Goal:

> build a relationship without revealing the “correct answer.”

## 14.2 LAB mode

Scientific/diagnostic mode.

May show:

- spikes;
- populations;
- DNs;
- root IDs;
- firing rates;
- inputs;
- outputs;
- causal tracing;
- timeline;
- seeds;
- simulation state;
- epistemic classifications.

Goal:

> prove what actually occurred.

Both modes must look at the **same real state**, never at different simulations fabricated for UI purposes.

---

# 15. PALETTE AND AESTHETICS

Recommended aesthetic direction:

- minimalist;
- dark background;
- thin lines;
- restrained light;
- precise geometry;
- ritual + technical appearance;
- low saturation by default;
- stronger pulses only when justified by activity.

Avoid:

- excessive cyberpunk neon;
- random particles;
- fire/smoke without causality;
- eyes;
- decorative wings;
- emotional symbols;
- automatic “mystical” text;
- mobile-game aesthetics.

The conceptual reference is:

> **a visual organism impossible to mistake for a person, but also impossible to mistake for a dead graph.**

---

# 16. SOUND

Sigil sound must be treated with the same rigor.

Do not use adaptive emotional music as though it were Flynn's psychological state.

Defensible possibilities:

- sonification of real activity;
- acoustic events generated by spikes/populations;
- timbres associated with specific modules;
- silence when there is no relevant activity.

Sonification must be optional and traceable.

UI sound may exist, but it must be clearly separated from sound “produced” by Flynn.

---

# 17. TIME

The interface needs to preserve temporality.

It matters to distinguish:

- current stimulus;
- immediate response;
- delayed response;
- persistence;
- return to baseline;
- changes between sessions;
- historical changes.

The sigil must not collapse everything into a single “current state” frame.

There may be a short visual memory, such as traces that fade as activity leaves the temporal window.

Permanent traces only with real persistent state.

---

# 18. FUTURE PLASTICITY

If plasticity is implemented and validated:

```text
FAFB BASE
+
persistent Δweights
```

then the sigil may represent plasticity as historical change.

But the rule will be:

```text
weight changed
≠
learned
```

Only functionally validated changes may receive stronger narrative/visual interpretation.

Even then, the visual should show **structural change**, not write “Flynn learned X.”

---

# 19. FUTURE HOMEOSTASIS

When a real and causal homeostatic variable exists, the sigil may indirectly reflect its influence.

Acceptable example:

```text
homeostatic state
→ changes circuit excitability
→ changes neural pattern
→ sigil changes because the neural pattern changed
```

Unacceptable example:

```text
hunger=0.8
→ sigil turns red
```

without neural mediation.

Manifestation must continue to pass through the brain.

---

# 20. CRITERION FOR A NEW VISUAL CHANNEL

A new functional channel enters the canonical sigil only if:

1. it exists in Flynn's connectome;
2. it has stable cellular identity;
3. it has a published causal function or equivalent high-evidence classification;
4. it can be read reproducibly at runtime;
5. it can be manifested visually without anthropomorphization.

Otherwise:

```text
KEEP_AS_UNKNOWN_SIGNAL
```

An unknown signal may be shown, but not given an invented functional meaning.
