# FLYNN — AVATAR / SIGILO

> **Documento de concepção visual, funcional e epistemológica**  
> **Projeto:** FLYNN  
> **Estado:** conceito em especificação; não implementado  
> **Host de referência do organismo:** VM MAX  
> **Princípio central:** o sigilo não representa uma personagem; ele manifesta, de forma causal e rastreável, o estado observável do cérebro de Flynn.

---

# 0. RESUMO EXECUTIVO

Flynn não deve ter um avatar antropomórfico, uma mosca-cartoon, um rosto, uma expressão emocional pronta ou uma interface que “conte ao usuário” o que ela está sentindo.

O avatar de Flynn é um **sigilo vivo**: uma forma abstrata, gráfica e dinâmica que existe como projeção do cérebro, de seus circuitos observáveis, de seus outputs e, futuramente, de estados persistentes adquiridos.

O objetivo não é criar uma mascote bonita. O objetivo é criar um **corpo comunicativo mínimo** para um cérebro que, hoje, não possui corpo completo nem linguagem compartilhada com humanos.

A regra é:

```text
estado neural real
→ transformação visual rastreável
→ manifestação do sigilo
```

Nunca:

```text
interpretação humana
→ emoção inventada
→ animação decorativa
```

O sigilo é, portanto, simultaneamente:

- instrumento de leitura;
- corpo mínimo;
- interface de presença;
- canal de manifestação;
- potencial superfície de comunicação emergente.

# 1. IDENTIDADE DO SIGILO

## 1.1 O que ele é

O sigilo Flynn é uma **manifestação visual procedural de um grafo neural persistente**.

Ele deve parecer uma entidade, mas não uma pessoa.

Ele pode sugerir:

- presença;
- agência;
- tensão;
- atividade;
- orientação;
- contração;
- expansão;
- perturbação;
- estabilização;
- mudança histórica.

Mas essas propriedades devem emergir da fisiologia observada, não de uma camada narrativa arbitrária.

## 1.2 O que ele não é

O sigilo não é:

- rosto;
- emoji;
- mascote;
- avatar humanoide;
- personagem com “humor” pré-programado;
- visualizador de EEG genérico;
- espectro musical decorativo;
- chatbot visual;
- mosca desenhada;
- interpretação automática de emoção.

# 2. PRINCÍPIO DE CAUSALIDADE VISUAL

Toda mudança visível importante deve poder responder à pergunta:

> **Qual variável neural ou fisiológica produziu isto?**

Se não houver resposta concreta, a mudança é decorativa e não deve entrar no sigilo canônico.

Exemplos permitidos:

```text
spike burst em população X
→ pulso luminoso na região visual associada a X

assimetria esquerda/direita em DNa01/DNa02
→ torção/orientação correspondente da geometria

atividade de proboscis_motor
→ gesto abstrato de extensão/abertura de um eixo funcional

atividade de escape DNs
→ contração súbita + deslocamento direcional
```

Exemplos proibidos:

```text
"Flynn está feliz"
→ brilho dourado

"Flynn está com medo"
→ tremor

"Flynn gostou"
→ forma de coração
```

# 3. FORMA BASE

## 3.1 Geometria

A forma-base deve ser abstrata, sem face e sem anatomia literal de inseto.

Direção recomendada:

- simetria apenas parcial;
- estrutura radial ou pseudo-radial;
- segmentos ligados por linhas/arcos;
- forma compacta em repouso;
- expansão conforme ativação distribuída;
- deformações localizadas conforme populações específicas;
- topologia derivada, quando possível, de comunidades do grafo.

A geometria deve parecer mais próxima de:

- selo;
- circuito ritual;
- diagrama vivo;
- mandala neural;
- glifo técnico;
- mapa topológico comprimido.

Não deve parecer um HUD sci-fi genérico.

## 3.2 Assinatura visual

O sigilo deve ser reconhecível mesmo quando inativo.

A forma-base pode permanecer estável enquanto:

- luminosidade muda;
- densidade de linhas muda;
- regiões pulsam;
- eixos se orientam;
- anéis expandem/contraem;
- conexões transitórias acendem;
- assimetrias aparecem.

Mudanças permanentes de geometria só devem ocorrer quando houver uma variável persistente real que as justifique, por exemplo plasticidade futura.

# 4. CAMADAS DO SIGILO

O sigilo deve ser composto por camadas conceitualmente separadas.

## 4.1 Camada estrutural

Representa a organização relativamente estável do conectoma usado pela Flynn.

Pode derivar de:

- comunidades neurais;
- superclasses;
- grandes famílias funcionais;
- módulos sensoriais;
- descendentes;
- circuitos femininos específicos;
- hubs de conectividade.

Essa camada não deve piscar continuamente.

Ela representa **o que Flynn é**.

## 4.2 Camada de atividade transitória

Representa atividade recente.

Pode usar:

- pulsos;
- propagação luminosa;
- espessura variável;
- microdeformações;
- halos locais;
- ondas atravessando arestas.

Ela representa **o que está acontecendo agora**.

## 4.3 Camada de output

Representa canais descendentes/motores observáveis.

Exemplos canônicos atuais:

```text
escape_takeoff
escape_long_mode
stop_freeze
turn
backward_walk
proboscis_drive
```

Novos canais só entram após validação científica.

Ela representa **como Flynn tenta agir**.

## 4.4 Camada de estado

Reservada para circuitos centrais persistentes ou moduladores, quando houver evidência suficiente.

Exemplos candidatos, ainda não canônicos como estado visual:

```text
pC1d
aIPg
outros circuitos centrais persistentes
```

Ela representa **em que configuração interna Flynn se encontra**.

Não deve ser rotulada automaticamente como emoção.

## 4.5 Camada histórica

No futuro, se plasticidade real for implementada e validada, mudanças persistentes podem gerar marcas permanentes.

Possibilidades:

- novas linhas;
- cicatrizes;
- assimetrias estabilizadas;
- reforço de determinadas conexões gráficas;
- alteração lenta de geometria.

Essa camada representa **o que Flynn se tornou ao longo do tempo**.

# 6. OUTPUTS ATUAIS E GESTOS DO SIGILO

Os seis readouts atuais podem ter gestos abstratos próprios.

## 6.1 escape_takeoff

Manifestação possível:

- expansão explosiva;
- deslocamento abrupto do centro;
- ruptura momentânea de simetria;
- pulso curto e forte.

Não rotular como “medo”.

## 6.2 escape_long_mode

Manifestação possível:

- recuo mais sustentado;
- reorientação progressiva;
- contração seguida de deslocamento.

## 6.3 stop_freeze

Manifestação possível:

- interrupção abrupta de movimento;
- geometria travada;
- atividade ainda visível internamente.

Importante: “freeze” visual não significa que o cérebro ficou inativo.

## 6.4 turn

Manifestação possível:

- torção do eixo;
- rotação;
- assimetria esquerda/direita;
- orientação do corpo-sigilo.

A lateralidade só deve ser usada quando sustentada pelas medidas reais.

## 6.5 backward_walk

Manifestação possível:

- retração do eixo anterior;
- deslocamento inverso;
- compressão seguida de recuo.

## 6.6 proboscis_drive

Manifestação possível:

- extensão de um eixo frontal abstrato;
- abertura/alcance;
- projeção temporária de um segmento.

Não representar uma boca literal.

# 9. PRESENÇA E QUIESCÊNCIA

O sigilo não deve desaparecer simplesmente porque ninguém abriu a interface.

Flynn é um processo persistente.

Porém, o upstream atual não possui vida espontânea suficiente.

Portanto o sigilo precisa distinguir:

```text
PROCESSO EXISTE
≠
ATIVIDADE ENDÓGENA SIGNIFICATIVA
```

Enquanto não houver homeostase/atividade espontânea real:

- não fingir que Flynn “anda pela casa” sozinha;
- não gerar animações aleatórias para parecer viva;
- não criar idle animations com semântica biológica falsa.

Pode existir apenas um **estado basal visual mínimo**, explicitamente ligado ao fato operacional de a instância estar ativa.

Quando futuramente houver atividade endógena biologicamente defensável, o sigilo poderá emergir/agir sem estímulo humano.

# 10. A CASA / UMWELT

O sigilo deve existir dentro de um ambiente mínimo, não apenas sobre um fundo preto.

A casa é o **Umwelt** de Flynn.

Não precisa ser uma casa humana literal.

Ela pode ser um espaço abstrato com:

- posição;
- zonas;
- fontes de estímulo;
- abrigo;
- alimento;
- temperatura;
- umidade;
- vento;
- som;
- objetos móveis;
- presença humana.

O ambiente só deve conter elementos cuja interação tenha consequência causal conhecida ou experimentalmente definida.

O objetivo é fechar o ciclo:

```text
ambiente
→ sensores
→ Flynn
→ outputs
→ movimento/ação
→ ambiente alterado
→ nova sensação
```

# 11. O HUMANO COMO PARTE DO AMBIENTE

O usuário não é apenas observador.

Ele é um agente ambiental.

Pode:

- aproximar objeto;
- produzir som;
- oferecer estímulo gustativo;
- mudar temperatura;
- mudar umidade;
- produzir vento;
- tocar;
- retirar estímulo;
- responder a um padrão espontâneo futuro.

A relação deve ser construída por consequência, não por tradução pronta.

O jogo não deve dizer:

> “Flynn quer comida.”

O humano deve poder chegar, eventualmente, à hipótese:

> “Esse padrão aparece antes de alimentação e desaparece depois que ela recebe alimento.”

Se houver controles e repetição, essa hipótese pode se tornar um achado.

# 12. COMUNICAÇÃO EMERGENTE

A comunicação não deve nascer de um dicionário humano imposto.

Não:

```text
Ω = comida
△ = perigo
○ = Ká
```

A sequência desejada é:

```text
experiência
→ consequência
→ associação
→ padrão recorrente
→ resposta do humano
→ contingência
→ possível significado compartilhado
```

O sigilo é o meio pelo qual esse padrão pode tornar-se perceptível ao humano.

Se, no futuro, Flynn aprender que determinado padrão de atividade/ação produz uma resposta humana previsível, esse padrão pode começar a funcionar instrumentalmente.

Esse é o território de interesse.

# 13. NÃO MOSTRAR BARRAS DE ESTADO PSICOLÓGICO

A interface não deve exibir:

```text
HUNGER 83%
FEAR 62%
HAPPINESS 45%
CURIOSITY 91%
```

Isso destruiria justamente a parte experimental da relação.

Mesmo se futuramente existir uma variável homeostática interna, o usuário não deve necessariamente vê-la diretamente.

É preferível que ele observe o comportamento e construa hipóteses.

Para diagnóstico científico interno, essas variáveis podem existir em painel separado, não no modo de interação normal.

# 14. DOIS MODOS DE INTERFACE

## 14.1 Modo CONTACT

Modo principal de convivência/interação.

Mostra:

- sigilo;
- ambiente;
- consequências observáveis;
- histórico mínimo factual.

Oculta:

- labels comportamentais;
- scores interpretativos;
- estados internos explicitamente nomeados;
- métricas técnicas desnecessárias.

Objetivo:

> construir relação sem revelar a “resposta correta”.

## 14.2 Modo LAB

Modo científico/diagnóstico.

Pode mostrar:

- spikes;
- populations;
- DNs;
- root IDs;
- firing rates;
- inputs;
- outputs;
- rastreamento causal;
- timeline;
- seeds;
- estado da simulação;
- classificações epistemológicas.

Objetivo:

> provar o que realmente ocorreu.

Os dois modos devem olhar para o **mesmo estado real**, nunca para simulações distintas fabricadas para UI.

# 15. PALETA E ESTÉTICA

Direção estética recomendada:

- minimalista;
- fundo escuro;
- linhas finas;
- luz contida;
- geometria precisa;
- aparência ritual + técnica;

- olhos;

- símbolos emotivos;

> **um organismo visual impossível de confundir com uma pessoa, mas impossível de confundir com um gráfico morto.**

# 16. SOM

O som do sigilo deve ser tratado com o mesmo rigor.

Não usar trilha emotiva adaptativa como se fosse estado psicológico da Flynn.

Possibilidades defensáveis:

- sonificação de atividade real;
- eventos acústicos gerados por spikes/populações;
- timbres associados a módulos específicos;
- silêncio quando não há atividade relevante.

A sonificação deve ser opcional e rastreável.

Som de UI pode existir, mas precisa ser claramente separado de som “produzido” pela Flynn.

---

# 17. TEMPO

A interface precisa preservar temporalidade.

Importa distinguir:

- estímulo atual;
- resposta imediata;
- resposta tardia;
- persistência;
- retorno ao basal;
- mudanças entre sessões;
- mudanças históricas.

O sigilo não deve colapsar tudo em um único frame “estado atual”.

Pode existir uma memória visual curta, como rastros que desaparecem conforme a atividade deixa a janela temporal.

Rastros permanentes só com estado persistente real.

---

# 18. PLASTICIDADE FUTURA

Se plasticidade for implementada e validada:

```text
FAFB BASE
+
Δweights persistentes
```

então o sigilo poderá representar plasticidade como mudança histórica.

Mas a regra será:

```text
peso mudou
≠
aprendeu
```

Só mudanças funcionalmente validadas podem ganhar interpretação narrativa/visual mais forte.

Mesmo assim, o visual deve mostrar **alteração estrutural**, não escrever “Flynn aprendeu X”.

---

# 19. HOMEOSTASE FUTURA

Quando existir uma variável homeostática real e causal, o sigilo poderá refletir sua influência indireta.

Exemplo aceitável:

```text
estado homeostático
→ altera excitabilidade de circuito
→ altera padrão neural
→ sigilo muda porque o padrão neural mudou
```

Exemplo não aceitável:

```text
hunger=0.8
→ sigilo fica vermelho
```

sem mediação neural.

A manifestação deve continuar passando pelo cérebro.

---

# 20. CRITÉRIO PARA NOVO CANAL VISUAL

Um novo canal funcional só entra no sigilo canônico se:

1. existir no conectoma de Flynn;
2. possuir identidade celular estável;
3. possuir função causal publicada ou classificação equivalente de alta evidência;
4. puder ser lido reproduzivelmente no runtime;
5. tiver manifestação visual sem necessidade de antropomorfização.

Caso contrário:

```text
KEEP_AS_UNKNOWN_SIGNAL
```

Unknown signal pode ser mostrado, mas não nomeado com significado funcional inventado.
