# Assets visuais de Flynn

Este diretório separa explicitamente **evidência visual de produto** de **arte conceitual**.

## screenshots/flynn

Capturas históricas da interface/runtime recuperadas. Elas demonstram que as superfícies visuais existiram, mas não provam isoladamente causalidade neural, continuidade residente, locomoção real ou consumo de recurso.

## concepts

Imagens conceituais geradas durante o desenvolvimento. São referências de exploração estética/arquitetural e **não devem ser usadas como evidência de execução**.

A proveniência detalhada, nomes-fonte e hashes estão em [../PRINTS_EVIDENCIA_VISUAL.md](../PRINTS_EVIDENCIA_VISUAL.md).
